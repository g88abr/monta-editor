# MONTA 🎬

**Plataforma que reúne ferramentas, recursos e comunidade para editores de vídeo.**

Projeto de **Gabriel & Miqueias**. O foco desde o primeiro dia é escala: muita gente usando, dados para analisar, melhorias no lugar certo. Dinheiro vem depois.

## Como abrir

É HTML/CSS/JS puro. **Não precisa instalar nada.**
